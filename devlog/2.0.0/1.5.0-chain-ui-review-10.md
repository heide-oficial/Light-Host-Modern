# 1.5.0 ? card and channel colors, review 10

| Before | After | Why |
| --- | --- | --- |
| Every Running/canvas card had the same surface. | Per-instance color tint through the context menu; presets, custom native picker and reset. | Identify elements without changing readable text or material behavior. |

## Implementation

Colors serialize in list instance XML and chain graph JSON. Old files retain default
colors. Host snapshots/events include colors. Graph audio-equivalence comparison strips
visual colors so edits and undo do not restart processing. Paired color edits affect both
physical channels. The animation reuses its brush rather than allocating each frame.

The shared picker follows native dialog/material/theme behavior. Its advanced section
uses a horizontal spectrum/controls layout when space permits and scrolls on shorter
windows. Card colors are deliberately softened to preserve contrast.
