# Chain mode and operating profiles

Implements the agreed List/Chain workflow locally for the next 1.5.0 development
portable. No GitHub changes or public release are part of this task.

## Host

- `RoutingGraph.h`: bounded, serializable DAG, explicit mono/stereo conversion,
  physical port identities, hidden-port and occupied-input validation.
- `RoutingRuntime.h`: preallocated processing buffers, output-reachable traversal,
  parallel latency compensation, full enabled plugin buses, smooth mixer gains,
  and per-port signal telemetry.
- `OperatingProfiles.h/.cpp`: atomic profile catalogue, migration, current/saved
  state comparison, activation, pending mode/profile, and graph history.
- Existing session XML carries mode, profile identity and routing data without
  replacing the existing recovery storage. Device restoration fails closed when
  a profile requests an unavailable device.
- IPC adds operating-state, operating-command, and routing-meters to protocol 4.
  Existing commands and List processing remain available.

## Interface

- `OperatingPresenter.h` integrates mode/profile controls, native dialogs,
  searchable profile selection, and the Profiles sidebar page.
- `ChainCanvas.h` provides native WinUI cards, drag wiring, pan/zoom, context
  actions, L/R visibility, mixer controls, animation and toolbar actions.
- Settings separates Operating mode from Appearance. Changes apply only after a
  full host restart; hiding the mode shortcut does not hide profile selection.
- English and Brazilian Portuguese labels cover the new workflow and errors.

## Verification scope

Native core, final application and WinUI compilation passed. Portable packaging
uses the repository build scripts and verifies binary versions, copies and the
WinUI source fingerprint. Build 0002 was packaged before the final one-time profile
migration correction; build 0003 includes that correction. No runtime tests
or manual audio/UI validation were executed for this iteration, following the
user's preference. The resulting dev-test portable is for manual review.
