Native validation covers 1/5/128 input-pair stereo sums sent to multiple outputs,
allocation-free audio callbacks, pair-removal remapping, invalid edits and persistence.
The host integration check uses an isolated no-audio profile, including undo/redo and
restart. UI screenshots and package checks are recorded after the final build.

## Results

- Eight PluginInstanceTests scenarios and the realtime suite passed, including the new
  variable mixer cases and the callback allocation audit.
- The isolated mixer integration exercised add/remove inputs and outputs, undo/redo,
  and restart persistence. A startup metadata write race was handled in the harness;
  an initial stale revision was rejected correctly, and a fresh run completed.
- Scripted UI review verified preset deletion, saving a custom HEX color, reopening the
  palette, hover, dynamic mixer controls, pair deletion and Appearance placement.
- Fixed a WinUI ownership error found during review: each wire visual layer now owns
  its own PathGeometry. Geometry objects cannot be shared between these paths.
