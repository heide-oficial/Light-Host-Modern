# Light Host Modern 1.2.0

## Added

- Added an in-app update notice backed by the latest GitHub release.
- Added a Support me page with Ko-fi access and an option to hide the page.
- Added name search and contextual sorting for running and installed plugins.
- Added JSON-based localization with `en-us.json` as the fallback language and a language selector in Settings.

## Improved

- Updated application and package metadata to version 1.2.0.
- Corrected release packaging to copy the current WinUI build and its locale files.
